    Connection

    Serial port, baud rate and line ending for each device. Settings are saved and the ports reopen automatically when the app starts.

    Simulation mode is ON: nothing is sent to the serial ports. The server answers like the rotary and the Alfies so the full checkout can be tested.
    Rotary (Arduino Mega · NEMA34)

    Firmware default: 9600 baud, Newline (LF). On connect the app waits for the Mega to start, sends the home command and waits for "HOME COMPLETE". Customers can only order after that.

    Alfie (USB-CAN adapter · SLCAN)

    Placeholders: {ID} 3-digit CAN ID, {DLC} data length, {DATA} hex bytes, {DATA_SP} hex bytes with spaces. Preview:

    C / S2 / O = close, 50 kbit/s (Alfie default), open, the same as VendingPoC.

    Alfie doors

    The Rotary XL has 3 doors, each with its own Alfie controller. Set each Alfie's address to match its Group ID and DIP switches. CAN ID = Group ID · Local address · 0xF.
