    Connection

    Serial port, baud rate and line ending for each device. Settings are saved and the ports reopen automatically when the app starts.

    Simulation mode is ON: nothing is sent to the serial ports. The server answers like the rotary and the Alfies so the full checkout can be tested.
    Rotary (Arduino Mega · NEMA34)

    Speeds, ramps and direction: Admin → Calibration → Motion.

    The carousel always spins while the dashboard is showing. Stopping it in Admin (Calibration, Test) only lasts while Admin is open. Order now stops it at the nearest column. At checkout it homes first (if switched on), then turns clockwise to the product's column and opens the door.

    Firmware default: 9600 baud, Newline (LF). On connect the app waits for the Mega to start, sends the home command and waits for "HOME COMPLETE". Customers can only order after that.

    Alfie (USB-CAN adapter · SLCAN)

    Placeholders: {ID} 3-digit CAN ID, {DLC} data length, {DATA} hex bytes, {DATA_SP} hex bytes with spaces. Preview:

    C / S2 / O = close, 50 kbit/s (Alfie default), open, the same as VendingPoC.

    Alfie doors

    The Rotary XL has 3 doors, each with its own Alfie controller. Set each Alfie's address to match its Group ID and DIP switches. CAN ID = Group ID · Local address · 0xF.

    AlfieNameGroup ID (0-3)Local address / DIP (0-15)CAN ID

    Rotary calibration

    Jog the carousel until a column is exactly in front of the door, then press Set on that column. Checkout sends GOTO <angle>, so the firmware never has to change. Needs the RotaryXL v06 firmware.

    Step

    ▶ turns clockwise, the only way the carousel runs. ◀ turns back and is only for calibration: finish each column with ▶, so it is set from the same side it is approached from.

    Motion

    The carousel always turns clockwise. These values are sent to the Arduino after every homing and when you press Save. Needs firmware v06.
